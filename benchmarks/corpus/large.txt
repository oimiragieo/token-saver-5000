## 1. Authentication

All endpoints require a valid API token. Obtain tokens via the OAuth2 flow or API key management
in the dashboard. Tokens expire after 24 hours; use the refresh endpoint to extend.

### 1.1 Obtain Token

**POST** `/auth/token`

Authenticate and receive an access token.

**Request Headers**

| Header         | Required | Description              |
|----------------|----------|--------------------------|
| Content-Type   | Yes      | `application/json`       |

**Request Body**

```json
{
  "grant_type": "password",
  "username": "user@example.com",
  "password": "s3cr3t"
}
```

**Parameters**

| Field        | Type   | Required | Description                  |
|--------------|--------|----------|------------------------------|
| `grant_type` | string | Yes      | Must be `password` or `api_key` |
| `username`   | string | Cond.    | Required for password grant  |
| `password`   | string | Cond.    | Required for password grant  |
| `api_key`    | string | Cond.    | Required for api_key grant   |

**Response** `200 OK`

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 86400,
  "refresh_token": "dGhpcyBpcyBhIHJlZnJlc2ggdG9rZW4..."
}
```

**Error Codes**

| Code | Status | Description                     |
|------|--------|---------------------------------|
| 1001 | 400    | Missing required field          |
| 1002 | 401    | Invalid credentials             |
| 1003 | 429    | Too many attempts, try again later |

---

### 1.2 Refresh Token

**POST** `/auth/refresh`

Exchange a refresh token for a new access token.

**Request Headers**

| Header         | Required | Description              |
|----------------|----------|--------------------------|
| Content-Type   | Yes      | `application/json`       |

**Request Body**

```json
{
  "refresh_token": "dGhpcyBpcyBhIHJlZnJlc2ggdG9rZW4..."
}
```

**Parameters**

| Field           | Type   | Required | Description              |
|-----------------|--------|----------|--------------------------|
| `refresh_token` | string | Yes      | Token from `/auth/token` |

**Response** `200 OK`

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 86400,
  "refresh_token": "bmV3IHJlZnJlc2ggdG9rZW4..."
}
```

**Error Codes**

| Code | Status | Description                  |
|------|--------|------------------------------|
| 1004 | 400    | Missing refresh_token        |
| 1005 | 401    | Invalid or expired token     |

---

### 1.3 Revoke Token

**DELETE** `/auth/token`

Revoke an access token immediately.

**Request Headers**

| Header          | Required | Description              |
|-----------------|----------|--------------------------|
| Authorization   | Yes      | `Bearer <access_token>`  |

**Response** `204 No Content`

**Error Codes**

| Code | Status | Description                  |
|------|--------|------------------------------|
| 1006 | 401    | Invalid or missing token     |

## 2. Users

User management endpoints for creating, reading, updating, and deleting user accounts.

---

### 2.1 Create User

**POST** `/users`

Create a new user account.

**Request Headers**

| Header          | Required | Description              |
|-----------------|----------|--------------------------|
| Authorization   | Yes      | `Bearer <access_token>`  |
| Content-Type    | Yes      | `application/json`       |

**Request Body**

```json
{
  "email": "alice@example.com",
  "name": "Alice Smith",
  "role": "member",
  "password": "SecurePassword123!"
}
```

**Parameters**

| Field      | Type   | Required | Description                          |
|------------|--------|----------|--------------------------------------|
| `email`    | string | Yes      | Must be unique, valid email format   |
| `name`     | string | Yes      | Display name, 2–100 characters       |
| `role`     | string | No       | `admin`, `member`, `viewer` (default: `member`) |
| `password` | string | Yes      | Min 8 chars, must include uppercase  |

**Response** `201 Created`

```json
{
  "id": "usr_01HV3B9ZQPK8MQNF7RM5XWDGT",
  "email": "alice@example.com",
  "name": "Alice Smith",
  "role": "member",
  "created_at": "2026-03-01T10:00:00Z",
  "updated_at": "2026-03-01T10:00:00Z"
}
```

**Error Codes**

| Code | Status | Description                          |
|------|--------|--------------------------------------|
| 2001 | 400    | Invalid email format                 |
| 2002 | 400    | Password does not meet requirements  |
| 2003 | 409    | Email already in use                 |
| 2004 | 422    | Missing required field               |

## 4. Tasks

Task management endpoints. Tasks belong to a project and can be assigned to users.

---

### 4.1 Create Task

**POST** `/projects/{project_id}/tasks`

Create a new task within a project.

**Request Headers**

| Header          | Required | Description              |
|-----------------|----------|--------------------------|
| Authorization   | Yes      | `Bearer <access_token>`  |
| Content-Type    | Yes      | `application/json`       |

**Path Parameters**

| Parameter    | Type   | Required | Description        |
|--------------|--------|----------|--------------------|
| `project_id` | string | Yes      | Project identifier |

**Request Body**

```json
{
  "title": "Design homepage mockup",
  "description": "Create wireframe and high-fidelity mockup for the new homepage",
  "assignee_id": "usr_01HV3B9ZQPK8MQNF7RM5XWDGT",
  "status": "todo",
  "priority": "high",
  "due_date": "2026-03-15",
  "labels": ["design", "frontend"]
}
```

**Parameters**

| Field         | Type     | Required | Description                                   |
|---------------|----------|----------|-----------------------------------------------|
| `title`       | string   | Yes      | Task title, 2–500 characters                  |
| `description` | string   | No       | Detailed description, max 10000 chars         |
| `assignee_id` | string   | No       | User ID to assign the task to                 |
| `status`      | string   | No       | `todo`, `in_progress`, `done` (default: `todo`) |
| `priority`    | string   | No       | `low`, `medium`, `high`, `critical` (default: `medium`) |
| `due_date`    | string   | No       | ISO 8601 date: `YYYY-MM-DD`                   |
| `labels`      | string[] | No       | Array of label strings (max 10)               |

**Response** `201 Created`

```json
{
  "id": "tsk_03PZMVCJRTU4SROE9WN8FZKHV",
  "project_id": "prj_02KXNWBHFST3RQND8VM7EYJCU",

  "description": "Create wireframe and high-fidelity mockup for the new homepage",
  "assignee_id": "usr_01HV3B9ZQPK8MQNF7RM5XWDGT",
  "status": "todo",
  "priority": "high",
  "due_date": "2026-03-15",
  "labels": ["design", "frontend"],
  "created_by": "usr_01HV3B9ZQPK8MQNF7RM5XWDGT",
  "created_at": "2026-03-01T12:00:00Z",
  "updated_at": "2026-03-01T12:00:00Z"
}
```

**Error Codes**

| Code | Status | Description                          |
|------|--------|--------------------------------------|
| 4001 | 400    | Missing or invalid title             |
| 4002 | 400    | Invalid status value                 |
| 4003 | 400    | Invalid priority value               |
| 4004 | 400    | Invalid due_date format              |

## 7. Error Reference

All error responses follow a consistent structure:

```json
{
  "error": {
    "code": 4008,
    "message": "Task not found",
    "details": null,
    "request_id": "req_07TDQAGNHXY8WURJ3AR2JDOTZ"
  }
}
```

### Global Error Codes

| Code | Status | Description                            |
|------|--------|----------------------------------------|
| 400  | 400    | Bad request — malformed input          |
| 401  | 401    | Authentication required                |
| 403  | 403    | Forbidden — insufficient permissions   |
| 404  | 404    | Resource not found                     |
| 409  | 409    | Conflict — resource already exists     |
| 422  | 422    | Unprocessable entity — validation error |
| 429  | 429    | Too many requests — rate limit hit     |
| 500  | 500    | Internal server error                  |
| 503  | 503    | Service unavailable                    |

### Rate Limiting

All endpoints are rate-limited. Limits are applied per API token.

| Tier   | Requests/minute | Burst |
|--------|-----------------|-------|
| Free   | 60              | 10    |
| Pro    | 600             | 100   |
| Enterprise | 6000        | 500   |

Rate limit headers are included on every response:

```
X-RateLimit-Limit: 600
X-RateLimit-Remaining: 598
X-RateLimit-Reset: 1743510060
```

When the rate limit is exceeded, the API returns `429 Too Many Requests` with a
`Retry-After` header indicating the seconds until the limit resets.

### Pagination

All list endpoints use cursor-less page-based pagination.

```json
{
  "data": [...],
  "meta": {
    "page": 2,
    "per_page": 20,
    "total": 142,
    "total_pages": 8
  }
}
```

Navigate pages with `?page=N`. Pages are 1-indexed.
The `total` field reflects the count after any filters are applied.

### Idempotency

Mutating endpoints (`POST`, `PATCH`, `DELETE`) support idempotent requests via the
`Idempotency-Key` header. Provide a unique key per logical operation; if the request
is retried with the same key within 24 hours, the original response is returned without
re-executing the operation.

```
Idempotency-Key: a8098c1a-f86e-11da-bd1a-00112444be1e
```

## 10. Attachments

File attachment endpoints for adding documents and images to tasks.

---

### 10.1 Upload Attachment

**POST** `/projects/{project_id}/tasks/{task_id}/attachments`

Upload a file and attach it to a task. Uses `multipart/form-data`.

**Request Headers**

| Header          | Required | Description                   |
|-----------------|----------|-------------------------------|
| Authorization   | Yes      | `Bearer <access_token>`       |
| Content-Type    | Yes      | `multipart/form-data`         |

**Path Parameters**

| Parameter    | Type   | Required | Description        |
|--------------|--------|----------|--------------------|
| `project_id` | string | Yes      | Project identifier |
| `task_id`    | string | Yes      | Task identifier    |

**Form Fields**

| Field    | Type | Required | Description                           |
|----------|------|----------|---------------------------------------|
| `file`   | file | Yes      | File to upload (max 25 MB)            |
| `name`   | text | No       | Override display name for the file    |

**Response** `201 Created`

```json
{
  "id": "att_09VESBAPOZYA XWRL5CT2KFQVB",
  "task_id": "tsk_03PZMVCJRTU4SROE9WN8FZKHV",
  "name": "homepage-mockup-v1.figma",
  "content_type": "application/octet-stream",
  "size_bytes": 4096000,
  "url": "https://cdn.taskflow.io/attachments/att_09VESBAPOZYA...",
  "uploaded_by": "usr_01HV3B9ZQPK8MQNF7RM5XWDGT",
  "created_at": "2026-03-03T14:00:00Z"
}
```

**Error Codes**

| Code  | Status | Description                       |
|-------|--------|-----------------------------------|
| 9001  | 400    | File exceeds 25 MB limit          |
| 9002  | 400    | File type not allowed             |
| 9003  | 404    | Task not found                    |
| 9004  | 403    | Not a project member              |
| 9005  | 507    | Storage quota exceeded            |
