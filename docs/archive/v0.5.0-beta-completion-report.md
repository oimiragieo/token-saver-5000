#### ✅ ThreadPoolExecutor for CPU-Bound Tasks
**Our Implementation:**
```python
async def _encode_async(self, texts: List[str]) -> np.ndarray:
    if not hasattr(self, "_executor"):
        self._executor = ThreadPoolExecutor(max_workers=1)

    loop = asyncio.get_event_loop()
    embeddings = await loop.run_in_executor(
        self._executor, lambda: self.model.encode(texts, show_progress_bar=False)
    )
    return embeddings
```

**Industry Standard (Manning "Python Concurrency with asyncio"):**
```python
async def main():
    loop = asyncio.get_running_loop()
    with ProcessPoolExecutor() as pool:
        tasks = [loop.run_in_executor(pool, long_task, i) for i in range(10)]
        await asyncio.gather(*tasks)
```

**Verdict:** ✅ **MATCHES BEST PRACTICES**
- Uses `asyncio.get_event_loop()` correctly
- Uses `loop.run_in_executor()` for CPU-bound work
- ThreadPoolExecutor appropriate for embedding generation
- Lazy initialization for efficiency in long-running server
